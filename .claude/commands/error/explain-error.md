# 분석대상
- $ARGUMENTS

# 설명항목
- 오류 현상: 어떤 오류가 발생하였는지 설명
- 발생 위치: 오류와 관련된 코드 및 위치 명시
- 발생 원인: 오류가 발생한 근본적 원인 설명
- 해결 방안: 실제 코드와 로그를 근거로 분석해 적절한 해결방법을 설명
- 코드 비교: 필요한 경우, 수정 전후의 코드 비교
- 유사 오류 및 해결 사례: 필요한 경우 현재 오류와 유사한 오류 사례를 제시하고, 발생 원인과 해결 방법을 코드 예제와 함께 설명해 주세요.

# 참고
- 실제 코드와 로그를 근거로 분석
- 불필요한 설명은 지양, 오류 복잡도에 따라 설명 수준 조절
- 사용자 승인 전까지 코드 수정하지 말 것
